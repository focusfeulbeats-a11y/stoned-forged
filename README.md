# STONEFORGE — pre-launch website prototype

Responsive static website concept for a UK stone-tools brand. Uses plain HTML, CSS and JavaScript; no build step required.

## Preview locally
Open `index.html` in a browser, or run a static server from this folder.

## Included
- Responsive desktop and mobile layouts
- Consistent SVG logo lockup, emblem and favicon
- Category filters
- Demo basket with quantity and subtotal
- Contact form that prepares an email via the visitor's email app

## Before launch
- Confirm business name availability and trademark/domain status.
- Replace `hello@stoneforge.co.uk` in `script.js` with a monitored business email.
- Verify product specifications, safety/conformity documentation, inventory, prices, shipping and returns.
- Product cards other than the proposed £8.99 disc are placeholders. The disc listing and basket are demo-only; checkout/payment is not connected.
- Add privacy, cookie (if needed), terms, shipping, returns, company and contact details.
- Set up real checkout (e.g. Shopify or another provider) before accepting payment. Do not take live orders through this prototype.
- Google Fonts are loaded from Google Fonts; system fallbacks are included.

## Deploy
Upload the contents of this folder to a new GitHub repository and connect that repository to Vercel as a static site. No build command is required; set the output/root directory to the repository root.
